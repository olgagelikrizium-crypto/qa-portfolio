# Как пополнять сайт

Все материалы хранятся в папке `data/` в JSON-файлах. HTML-страницы трогать не нужно:
добавили запись в JSON, и она сама появилась на сайте.

> Смотреть сайт на компьютере нужно через **Live Server** в VS Code (правый клик по `index.html` → *Open with Live Server*).
> Если просто открыть файл двойным кликом, данные из JSON не загрузятся. Так браузер защищает локальные файлы, это не ошибка сайта.

## Новый баг-репорт → `data/bugs.json`
Скопируйте любой существующий баг, вставьте его в список (между `{ }`, не забудьте запятую между записями) и поменяйте поля:

| Поле | Что писать |
|---|---|
| `id` | Уникальный ID, например `"Web 301"` |
| `title` | Заголовок по формуле What? Where? When? |
| `project` | `"Capital.com"`, `"E-commerce Platform"`, `"AI Design Tool"` или новый проект: он сам появится в фильтре |
| `source` | Откуда баг: `"ITX internship"`, `"Test IO"`… |
| `date` | `"ДД.ММ.ГГГГ"` |
| `type` | `"Functional"` или `"Non-functional"` |
| `severity` | `"Critical"`, `"Major"`, `"Minor"`, `"Trivial"` |
| `priority` | `"High"`, `"Medium"`, `"Low"` |
| `platforms` | `["Desktop"]`, `["Mobile"]` или `["Desktop", "Mobile"]` |
| `tags` | Области: `"Navigation & links"`, `"Localization"`, `"UI / Visual"`, `"Content"`, `"Search & filters"`, `"AI features"`, `"Cross-license routing"`. Можно придумать новый тег, он сам станет фильтром |
| `featured` | `true`, чтобы показать баг на главной (лучше держать 6 штук) |
| `evidence` | `"videos/имя_файла.mp4"` или `null`, если видео нет |
| `note` | Текст на случай, когда видео нет (например, из-за NDA) |

## Новая заметка («Золотая жила», чек-лист, урок) → `data/notes.json`
- `type`: `"golden"` (паттерн бага), `"checklist"` (чек-лист) или `"lesson"` (урок, вывод)
- `sections`: блоки текста. Каждый блок — одно из трёх:
  - `{ "h": "Заголовок", "p": "Абзац" }`
  - `{ "h": "Заголовок", "list": ["пункт", "пункт"] }`
  - `{ "h": "Заголовок", "check": ["пункт чек-листа"] }` — пункты с квадратиками
- `related_bugs`: ID ваших багов, например `["Web 109"]`. Их карточки появятся под заметкой.

## Новый сертификат → `data/certificates.json`
Картинку положите в `images/certificates/`. Имя файла только латиницей, без пробелов.

## Новый аудиоурок
1. Файл mp3 → `audio/<тема>/lesson-08.mp3`
2. Транскрипт → `transcripts/<тема>/lesson-08.json`
3. Запись об уроке → `data/<тема>.json`
4. Новая тема → запись в `data/catalog-index.json` + файл `data/<тема>.json`. Темы без уроков на сайте не показываются.

## Меню
Пункты меню задаются в одном месте: `js/site.js`, массив `NAV`.
